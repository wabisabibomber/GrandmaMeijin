# GrandmaMeijin

Windows 11（x64）用の、小さなマウス左クリック連打ツールです。クリックの周期と、ボタンを押している時間の割合（デューティー比）を指定できます。

## 起動と使い方

配布用の `GrandmaMeijin.exe` を起動してください。インストールや.NET・Visual C++ランタイムの追加インストールは不要です。

1. **クリック周期（ms）**を設定します。初期値は60ms、設定範囲は20～60,000msです。
2. **押下時間の割合（%）**を設定します。初期値は50%、設定範囲は1～99%です。
3. クリックしたい場所にマウスポインターを移動し、**F8**を押すと連打が始まります。
4. もう一度**F8**を押すと停止します。画面の「開始」「停止」ボタンでも操作できます。
5. 60ms周期で焼くのが最適らしいです。さらなる高速化は自己責任で。

状態は **STOPPED** / **RUNNING** で表示します。連打中は周期・割合・ホットキーを変更できません。ウィンドウを閉じると停止して終了します。

エラーはポップアップで通知します。通知前に連打を停止し、通知を閉じても自動では再開しません。保存失敗が続く場合は、同じ通知を繰り返し表示しません。

周期と押下時間の割合は自動保存され、次回起動時に復元します。起動時は常に停止状態です。

## 周期と押下時間

周期は、ボタンを押している時間（Down）と離している時間（Up）の合計です。

| 周期 | 押下時間の割合 | Down | Up |
| --- | --- | --- | --- |
| 60ms（初期値） | 50%（初期値） | 30ms | 30ms |
| 100ms | 50% | 50ms | 50ms |
| 100ms | 30% | 30ms | 70ms |
| 101ms | 50% | 50.5ms | 50.5ms |

設定欄の下にDown / Upの時間を表示します。実際のタイミングはWindowsの負荷などにより変動します。極端に短い押下・解放時間は、表示どおりの精度にならない場合があります。

## ホットキーの変更

「変更…」を押し、キーと必要な修飾キー（Ctrl / Alt / Shift / Win）を選んで「適用」を押します。例：`F8`、`Ctrl + Shift + A`、`Alt + F9`。

- 初期値はF8です。アプリが非アクティブでも動作します。
- Fキー以外は、1つ以上の修飾キーが必要です。
- F12はWindowsの予約キーです。OSの予約操作や他アプリが使用している組み合わせも登録できません。
- 登録に失敗した場合は元の設定を維持します。起動時に登録できなかった場合はボタン操作を利用できます。
- 設定したホットキーは次回起動時にも復元します。

## 利用上の注意

- 現在のマウスポインター位置へ入力します。対象アプリに切り替え、位置を確認してからホットキーで開始してください。
- 管理者権限で動作するアプリなどには入力が届かない場合があります。対象アプリによってはソフトウェアからの入力を受け付けません。
- 停止・終了時は左ボタンを離す入力を送ります。強制終了やOS停止など、終了処理を実行できない状況は対象外です。
- 設定は `%LOCALAPPDATA%\GrandmaMeijin` 内に保存します。周期と押下時間の割合は `click.json`、ホットキーは `hotkey.json` です。初期化する場合はアプリ終了後に対応するファイルを削除してください。以前のバージョンで保存したホットキーも引き続き利用できます。
